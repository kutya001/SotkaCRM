**Статус:** В работе

## 1. Архитектурный контекст и цели

Перенос логики фильтрации данных из глобальной кнопки верхнего тулбара:
1. **В табличном режиме (`viewMode === 'table'`):** фильтрация размещается непосредственно в заголовках столбцов таблицы (`<th>`). Каждая фильтруемая колонка получает интерактивную кнопку-иконку воронки (`Filter` из Lucide React), открывающую контекстный поповер с текстовым поиском, чекбоксами уникальных/категориальных значений и числовыми/календарными диапазонами (в зависимости от типа поля). При активном фильтре иконка подсвечивается акцентным цветом и показывает бейдж количества активных критериев.
2. **В карточном режиме (`viewMode === 'cards'`):** в тулбаре формируется компактная строка управления группировкой и фильтрами:
   `[ Группировка: {Select} ] [ Фильтры {Icon + Badge} ] [ Поиск ]`, где кнопка «Фильтры» открывает выпадающее меню со списком доступных фильтров по сущности, не деформируя сетку карточек.
3. **Глобальный поиск и сброс:** в основном тулбаре остается строка быстрого поиска, переключатель видов и адаптивная кнопка «Сбросить все фильтры» (появляющаяся только при наличии активных условий).

## 2. Пошаговый план изменений

### Шаг 1: `components/ui/DataJournal.tsx`
- Расширить интерфейс `ColumnDef<T>`:
  - `filterable?: boolean` (по умолчанию `true`);
  - `filterType?: 'text' | 'select' | 'range' | 'dateRange'`;
  - `filterOptions?: { value: string; label: string }[]`;
  - `groupable?: boolean` (для группировки в карточном режиме).
- Модель состояния фильтрации:
  ```typescript
  export interface ColumnFilterState {
    search?: string;
    selectedValues?: string[];
    rangeMin?: number | string;
    rangeMax?: number | string;
  }
  export type ColumnFilters = Record<string, ColumnFilterState>;
  ```
- Реализовать расчет уникальных значений для категориальных колонок на основе переданного массива данных.
- Добавить компонент `ColumnFilterPopover`:
  - Клик с `e.stopPropagation()` для исключения случайной сортировки по клику на заголовок `<th>`.
  - Закрытие по клику вне области (Click Outside) и по клавише Escape.
  - Поле поиска по подстроке.
  - Чекбоксы уникальных значений со счетчиками записей, кнопками «Выбрать все» и «Снять все».
  - Диапазоны «От» / «До» для дат и чисел/валют.
  - Кнопка локального сброса фильтра колонки.
- Тулбар режима таблицы:
  - Удалить устаревшую глобальную кнопку «Фильтры».
  - Встроить поле глобального поиска с кнопкой быстрой очистки.
  - Добавить кнопку «Сбросить все фильтры» с бейджем активных фильтров.
- Карточный режим (Канбан):
  - Добавить селектор группировки `groupBy`: «Без группировки» + список группируемых колонок (`status`, `manager_id`, и т.д.).
  - Добавить кнопку «Фильтры» рядом с селектором группировки, открывающую компактный поповер фильтров сущности.
  - Реализовать отображение карточек по группам (колонки / секции с подсчетом количества), если группировка активна.
