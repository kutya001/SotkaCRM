## 1. Архитектурный обзор и цели

1. **Рефакторинг регистра выплат в полнофункциональный реестр «Операции по ЗП»:**
   - Таблица `employee_payouts` расширяется полями `operation_sign` (`+` / `-`), `operation_type` (`accrual_connection`, `accrual_maintenance`, `salary_base`, `bonus_other`, `deduction`, `fine`, `payout`), `connection_id`, `seller_phone`, `actual_date`, `settlement_month`, `note`, `payment_method`, `amount`.
   - В RPC `link_lead_to_seller` автоматически создается начисление по подключению (`+`, `accrual_connection`).
   - В RPC `run_maintenance_billing` автоматически создаются ежемесячные начисления сопровождения (`+`, `accrual_maintenance`).
   - RLS: консультант и SMM видят только свои операции; администратор и руководитель — все операции. Модификации (`INSERT`, `UPDATE`, `DELETE`) — строго роль `admin`.
   - Интерфейс переименовывается в «Операции по ЗП» (маршрут `/payouts` и при необходимости редирект), обновляются колонки реестра, тулбар (кнопка «Расчётный лист»), форма создания операции.

2. **Модуль «Продавцы»:**
   - Полное закрытие/удаление редактирования статуса модерации из карточек, модальных окон и таблиц.
   - Табы фильтрации переводятся на категории кураторства: «Все», «Мои продавцы» (по умолчанию для консультанта), «Без куратора» (с иконками Lucide, без эмодзи).
   - Мгновенное закрытие дропдауна куратора (`setIsOpen(false)`) сразу после выбора.
   - Блокировка связывания продавца с лидом при наличии назначенного куратора (`manager_id !== null`) в UI и API (`400 Bad Request`).

3. **Модуль «Подключения»:**
   - Добавление в таблицу и карточки колонок финансового баланса по подключению: «Итого бонусы», «Выплачено», «Остаток».
   - FSM жизненного цикла подключений: `подключен` -> `сопровождение` -> `готов` / `приостановлен` (при `sellers.is_active = false`). Блокировка ручной смены статусов — статус управляется автоматически.
   - В деталях подключения блок «История начислений ЗП» со списком операций по данному `connection_id`.

4. **Навигация:**
   - Переименование раздела в `DesktopSidebar.tsx`, `MobileBottomBar.tsx`, `MobileMenuDrawer.tsx` на «Операции по ЗП» с иконкой `Receipt` / `WalletCards`.

5. **Синхронизация документации:**
   - `DB.md` и `public/openapi.json`.
