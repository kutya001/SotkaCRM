## 1. Задачи и декомпозиция

### 1.1. Экран входа `/login` (Apple Island Glassmorphism)
- Матовая карточка в соответствии с `UxUi.md`:
  - `backdrop-blur-xl bg-white/75 dark:bg-zinc-900/75 border border-white/20 dark:border-zinc-800/40 rounded-3xl`.
  - Эффект матового стекла, плавные тени, отступы.
- Поля ввода:
  - Идентификатор пользователя (Email, логин `admin` / `consultant1` / `smm_operator` или телефон).
  - Пароль.
- Интерактивные элементы:
  - Кнопка отправки формы с анимированным лоадером (`Loader2`).
  - Переключатель темы оформления (`ThemeToggle` с контурными Lucide иконками `Sun` / `Moon`).
  - Блок отображения ошибок валидации и блокировки доступа (`AlertCircle`).
  - Строго без эмодзи.

### 1.2. Server Action аутентификации (`app/auth/actions.ts`)
- Распознавание входных данных (email / login):
  - Поиск по таблице `users` для резолва логина в email или прямой вход.
- Проведение авторизации в Supabase Auth через `signInWithPassword`.
- Извлечение профиля сотрудника из таблицы `users` по `auth_id = user.id`.
- Проверка инварианта активности `is_active`:
  - Если `is_active = false`: принудительный вызов `signOut` и возврат ошибки: «Учетная запись заблокирована администратором».
- Корректная установка сессионных cookies и редирект на `/`.

### 1.3. Интеграция тестовых учетных записей в Supabase Auth
- Создание учетных записей в `auth.users` и `auth.identities`:
  - `admin@sotka.kg` (пароль: `admin123456`) -> привязка к `users.user_id = 'a0000000-0000-0000-0000-000000000001'`.
  - `consultant@sotka.kg` (пароль: `consultant123456`) -> привязка к `users.user_id = 'c0000000-0000-0000-0000-000000000001'`.
  - `smm@sotka.kg` (пароль: `smm123456`) -> привязка к `users.user_id = 'b0000000-0000-0000-0000-000000000001'`.
- Связывание внешнего ключа `users.auth_id = auth.users.id`.

### 1.4. Ролевой Middleware (`lib/supabase/middleware.ts` & `middleware.ts`)
- Обновление JWT-токенов через `@supabase/ssr`.
- Защита маршрутов:
  - Неавторизованный пользователь перенаправляется на `/login`.
  - Авторизованный пользователь при попытке зайти на `/login` перенаправляется на `/`.
- Ролевые ограничения (RBAC):
  - `/admin/*`, `/plans/*` — строго `admin`.
  - `/sellers`, `/payments`, `/connections`, `/payouts` — доступны `admin` и `consultant`.
  - `smm` имеет доступ строго к `/leads`, `/profile` и дашборду. При попытке доступа к запрещенным финансовым разделам или каталогу продавцов — редирект на `/leads`.

### 1.5. Глобальный адаптивный каркас Apple Island (`components/layout/`)
- **Десктоп (>= 1024px):**
  - Матовый сайдбар: `w-64` в развернутом виде, `w-18` (72px) в свернутом, `rounded-3xl`, фиксация `fixed top-4 left-4 bottom-4`.
  - Плавная смена ширины, контурные иконки Lucide (`strokeWidth={1.75}`), подсветка активного раздела.
  - Плавающий Top Header: `fixed top-4 right-4 z-30`, выравнивание с сайдбаром (`left-72` / `left-24`).
  - Поиск, статус синхронизации API (только для `admin`), `ThemeToggle`, профиль сотрудника.
- **Мобильный (< 1024px):**
  - Верхний матовый островок с заголовком модуля, кнопкой «Лупа» (раскрывающийся input с анимацией и автофокусом) и кнопкой «Фильтр».
  - Нижняя плавающая таблетка навигации: `fixed bottom-4 left-4 right-4 h-16 rounded-2xl island-glass`.
  - Круглая кнопка FAB: `w-14 h-14` в нижнем правом углу (`fixed bottom-24 right-5`) под большой палец.
- **Рабочая область:**
  - Плавный скролл, сохранение состояния островков без мерцания.
