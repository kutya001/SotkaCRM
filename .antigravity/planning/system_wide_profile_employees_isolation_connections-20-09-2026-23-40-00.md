# Архитектурный план: Профиль, Управление сотрудниками, Изоляция данных, Назначение кураторов и Связи

## 1. Контекст и цели

Пользователь запросил масштабное расширение функционала системы:
1. **Навигация в профиль на ПК:**
   - Клик по аватару/профилю в шапке (`TopHeader`) рядом с переключателем темы.
   - Клик по блоку пользователя внизу боковой панели (`DesktopSidebar`).
   - Добавление ссылки на модуль «Сотрудники» (`/employees`) в боковой панели для администратора.
2. **Редактирование профиля и доступ администратора к любым пользователям (`/profile`):**
   - Возможность для каждого пользователя изменить свои данные (`full_name`, `phone`) и сменить пароль.
   - Для роли `admin`: возможность выбрать любого сотрудника, просмотреть его профиль/KPI, изменить любые данные и сбросить пароль.
3. **Новый модуль «Сотрудники» (`/employees`):**
   - Реестр сотрудников на базе `DataJournal` (таблица на десктопе, карточки на мобильных).
   - Создание нового сотрудника (логин, пароль, ФИО, телефон, роль: `admin` | `consultant` | `smm`).
   - Редактирование данных, блокировка/разблокировка (`is_active`), сброс пароля.
4. **Строгая изоляция данных и аналитики:**
   - Разграничение видимости: консультант видит исключительно свои лиды (`assigned_to = user_id`), своих продавцов (`manager_id = user_id`), свои закрепления и выплаты.
   - SMM видит исключительно свои созданные лиды (`created_by = user_id`).
   - Администратор видит все данные компании.
   - Актуализация SQL RPC `get_leads_funnel_stats()` и `get_sellers_kpi_stats()`, RLS-политик и серверных экшенов.
5. **Модуль «Продавцы»: отображение лида и назначение куратора с интеграцией в `connections`:**
   - В таблице и модальном окне продавца отображается связанный с ним лид (номер, имя клиента, статус).
   - Возможность быстрого назначения куратора (`manager_id`).
   - При назначении/смене куратора автоматически создается или обновляется запись в таблице `connections` с расчетом комиссии по формуле `(plan_price * connection_percent) / 100`, что сразу поступает в расчет зарплат и выплат.
6. **Быстрые действия в Лидах:**
   - Быстрое переназначение консультанта администратором (в таблице, карточках и модальном окне).

## 2. Архитектурная декомпозиция и план реализации

### Этап 1: Навигация (Шапка и Сайдбар)
- `components/layout/DesktopSidebar.tsx`: обернуть блок пользователя в `<Link href="/profile">`, добавить `/employees` в `NAV_ITEMS` с фильтром `roles: ['admin']`.
- `components/layout/TopHeader.tsx`: обернуть аватар в `<Link href="/profile">`, добавить `/employees` и `/profile` в `MODULE_TITLES`.
- `components/layout/MobileHeader.tsx`: добавить `/employees` и `/profile` в `MODULE_TITLES`.

### Этап 2: Изоляция данных в базе данных (Миграция 006)
- Обновить SQL-функции:
  - `get_leads_funnel_stats()`: для консультанта фильтр строго `WHERE assigned_to = v_user_uuid`.
  - `get_sellers_kpi_stats()`: для консультанта фильтр `WHERE manager_id = v_user_uuid`.
  - RLS-политику `leads_select_policy`: консультант видит только `assigned_to = get_current_crm_user_id()`.
- Актуализировать `DB.md`.

### Этап 3: Модуль «Профиль» (`/profile`)
- `app/profile/actions.ts`:
  - `updateUserProfile(data: { full_name?: string; phone?: string; targetUserId?: string })`
  - `changeUserPassword(data: { oldPassword?: string; newPassword: string; targetUserId?: string })`
  - `getAllUsersForAdmin()`
- `app/profile/page.tsx`:
  - Модальное окно редактирования своего профиля.
  - Модальное окно смены пароля.
  - Для администратора: переключатель пользователей, возможность редактировать любого сотрудника и сбрасывать ему пароль.

### Этап 4: Новый модуль «Сотрудники» (`/employees`)
- `app/employees/actions.ts`:
  - `getEmployees()`
  - `createEmployee()`

  - `toggleEmployeeActive()`
  - `resetEmployeePassword()`
- `app/employees/page.tsx`:
  - `DataJournal` (Table View + Card View), модальные окна создания/редактирования/сброса пароля.

### Этап 5: Модуль «Продавцы» (Связанный лид + назначение куратора ↔ connections)
- `app/sellers/actions.ts`:
  - В `getSellers` добавить маппинг связанного лида (`leads.seller_phone = sellers.seller_phone`).
  - Экшен `assignSellerManagerAndSyncConnection(sellerPhone, managerId)`.
- `app/sellers/page.tsx`:
  - Колонка «Связанный лид» и блок в `EntityModal`.
  - Быстрое назначение куратора для администратора.

### Этап 6: Быстрые действия в Лидах
- `app/leads/page.tsx`:
  - Быстрое переназначение консультанта администратором прямо из строки/карточки и модалки.

### Этап 7: Синхронизация документации и тестирование
