## 1. Обзор реализованной архитектуры системы

SotkaCRM — корпоративная CRM-система для управления воронкой продаж, учета продавцов платформы Sotka, автоматизации взаиморасчетов с консультантами и контроля клиентского сопровождения.

### Ключевой стек технологий
- **Фреймворк:** Next.js 15 (App Router, React 19, Server Actions, Route Handlers).
- **База данных:** PostgreSQL 15+ (Supabase) с типами `ENUM`, индексами, связями внешних ключей и Row Level Security (RLS).
- **Стилизация и дизайн:** Tailwind CSS, эстетика Apple Island (Glassmorphism: `backdrop-blur-xl bg-white/75 dark:bg-zinc-900/75`), контурные иконки Lucide React (`strokeWidth={1.75}`). Полное отсутствие эмодзи в интерфейсе.
- **Интеграция:** Серверный шлюз синхронизации с внешним API `https://api.sotka.kg`.

## 2. Реестр модулей и функциональное покрытие

### Этап 1: Инфраструктура базы данных и Supabase
- 11 реляционных таблиц (`users`, `leads`, `sellers`, `payments`, `connections`, `employee_rates`, `client_maintenance`, `employee_payouts`, `outlets`, `plans`, `plans_history`).
- 6 пользовательских перечислений (`user_role`, `lead_status`, `client_lifecycle_status`, `maintenance_status`, `payout_category_type`, `seller_moderation_status`).
- Триггеры базы данных:
  - `prevent_lead_delete`: блокировка физического удаления лидов (только перевод в статус `Отмена`).
  - `audit_plan_price_trigger`: автоматическое протоколирование изменений цен тарифов в `plans_history`.
- RLS-политики безопасности для всех таблиц с разделением прав `admin`, `consultant`, `smm`.

### Этап 2: Аутентификация, Middleware и каркас интерфейса
- Экран входа `/login` в эстетике Apple Island с авторизацией строго по рабочим логинам (инкапсуляция в `${login}@internal.sotka.kg`).
- `middleware.ts`: ролевая маршрутизация, обновление токенов сессий, защита приватных маршрутов.
- Лейаут: адаптивный `DesktopSidebar`, плавающий `TopHeader`, мобильный `MobileHeader`, `MobileBottomBar` и `FAB`.

### Этап 3: Полиморфный реестр `DataJournal` и форма `EntityModal`
- `DataJournal`: переключение табличного (десктоп) и карточного (смартфоны) видов, поиск, конструктор фильтров, sticky-шапка, серверная пагинация.
- `EntityModal`: режимы `view`, `edit`, `create`, валидация полей, быстрые действия (звонок, WhatsApp, Instagram).

### Этап 4: Пайплайн входящих заявок («Лиды» `/leads`)
- Воронка статусов: `Открыт` → `Обработан` → `Назначен` → `Подписан` | `Отмена`.
- Обязательный диалог отмены сделки с указанием причины в `comment`.
- База скриптов продаж `data/sales-scripts.json` со шторкой `SalesScriptsSheet`, копированием в буфер обмена и тактильным виброоткликом `navigator.vibrate(50)`.

### Этап 5: Серверная синхронизация с API `api.sotka.kg`
- Серверный модуль `lib/services/sotka-api.ts`: двухфакторная аутентификация через `/api/public/v1/auth/pair`, получение списков продавцов и транзакций с пагинацией `limit/offset`.
- Route Handler `/api/sync/sotka`: доступен только администратору, сохраняет локально назначенных менеджеров (`sellers.manager_id`), фиксирует платежи в `payments`.
- Реестр продавцов платформы `/sellers` с балансами и аналитикой.
- Исправлен веб-манифест PWA `/manifest.webmanifest`.

### Этап 6: Ручной маппинг «Лид → Продавец» и модуль «Подключения» (`/connections`)
- Изоляция свободных продавцов: выборка только тех `sellers`, чьи телефоны не фигурируют в `leads.seller_phone`.
- Модальное окно `LeadSellerMappingModal` с живым предпросмотром комиссии консультанта (30%).
- Атомарная привязка: перевод лида в `Подписан`, закрепление `sellers.manager_id`, создание строки в `connections`.
- Реестр `/connections`: фильтрация по периодам `accrual_month`, статусам жизненного цикла (`новый`, `подключен`, `сопровождение`, `готов`, `отменен`), управление статусом администратором.

### Этап 7: Финансы, сопровождение, справочники и профиль
- **Выплаты персоналу (`/payouts`)**: учет зарплат, авансов, премий и удержаний; фильтры, KPI фонда выплат, создание выплаты администратором.
- **Биллинг сопровождения (`client_maintenance`)**: автоматический расчет 10% от тарифа активным клиентам (до 3 месяцев), модальное окно запуска для администратора в `/connections`.
- **Справочники (`/plans` и `/rates`)**:
  - Каталог тарифов с аудитом изменения цен через `plans_history`.
  - Реестр персональных ставок мотивации сотрудников.
- **Профиль пользователя (`/profile`)**:
  - Карточка сотрудника с контактными данными и системной ролью.
  - Переключатель темы (Светлая / Тёмная / Системная).
  - Персональный KPI-дашборд с адаптацией под роли SMM, Консультанта и Администратора.
- **Стартовый дашборд (`/`)**:
  - Оперативный обзор ключевых показателей CRM, оперативные счетчики, быстрые ссылки на все модули и последние поступившие лиды.
