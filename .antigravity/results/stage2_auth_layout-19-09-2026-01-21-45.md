## 1. Выполненные работы

### 1.1 Экран входа `/login`
- Разработан в соответствии со спецификацией `UxUi.md`:
  - Матовая карточка Apple Island: `backdrop-blur-xl bg-white/75 dark:bg-zinc-900/75 border border-white/20 dark:border-zinc-800/40 rounded-3xl`.
  - Поля ввода логина/пароля с контурными иконками Lucide React (`User`, `Lock`, `Layers`, `ArrowRight`, `AlertCircle`, `Loader2`).
  - Переключатель темы (светлая/тёмная) в правом верхнем углу.
  - Строгий запрет эмодзи соблюден во всех текстовых узлах и интерфейсе.
  - Поддержка ввода коротких логинов (`consultant1`, `smm_operator`, `admin`) с авторезолвом к почтовому домену `@sotka.kg`.

### 1.2 Server Actions авторизации (`app/auth/actions.ts`)
- Метод `login(prevState, formData)`:
  - Выполняет `signInWithPassword` через Supabase Auth.
  - Запрашивает профиль пользователя из таблицы `users` по `auth_id`.
  - Проверяет активность сотрудника: `is_active = true`. Если учетная запись отключена или заблокирована, выполняется `signOut` и возвращается ошибка.
  - При успехе выполняет инвалидацию кеша `revalidatePath('/', 'layout')` и перенаправление на дашборд.
- Метод `signOut()`:
  - Выполняет `supabase.auth.signOut()`, сброс кэша и редирект на `/login`.

### 1.3 Middleware ролевого доступа (`middleware.ts` и `lib/supabase/middleware.ts`)
- Обновление сессионных cookie через `@supabase/ssr`.
- Защита маршрутов:
  - Неавторизованные пользователи перенаправляются на `/login`.
  - Заблокированные (`is_active = false`) принудительно разлогиниваются.
  - Маршруты `/admin/*` и `/plans/*` защищены строго для роли `admin`.
  - Для роли `smm` заблокирован доступ к `/sellers`, `/payments`, `/connections`, `/payouts` (авторедирект на `/leads`).

### 1.4 Глобальный адаптивный каркас Apple Island (`UxUi.md`)
- **Desktop (>=1024px)**:
  - Сворачиваемый матовый сайдбар: ширина `w-64` (развернут) / `w-[72px]` (свернут), скругление `rounded-3xl`, индикаторы активного пункта меню.
  - Плавающий верхний островок Top Header с отступом `left-72` / `left-24`.
- **Mobile (<1024px)**:
  - Матовая верхняя панель с плавной анимацией разворачивания строки поиска и кнопкой фильтров.
  - Нижняя плавающая навигационная панель (`rounded-2xl`).
  - Плавающая круглая кнопка добавления (FAB `w-14 h-14` в правом нижнем углу `bottom-24 right-5`).
- **Смена ролей и навигация**:
  - Центральная область обновляется без перезагрузки всей страницы и без мигания окружающих островков.

### 1.5 Инфраструктура типизации
