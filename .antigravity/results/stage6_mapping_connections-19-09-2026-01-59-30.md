## 1. Выполненные задачи и архитектурные решения

### 1.1. Серверные действия маппинга (`app/leads/mapping-actions.ts`)
1. **Выборка свободных продавцов (`getAvailableSellersForMapping`)**:
   - Формирует список занятых продавцов через запрос уникальных `seller_phone` из таблицы `leads`.
   - Запрашивает продавцов из `sellers`, исключая телефоны, уже привязанные к лидам.
   - Фильтрует по поисковому запросу (`seller_name`, `store`, `seller_phone`).
   - Возвращает каждого продавца с информацией о текущем тарифе (`plans.plan_id`, `name`, `price_kgs`), дате регистрации и балансе.
2. **Расчет индивидуальной ставки консультанта (`getConsultantRate`)**:
   - Обращается к таблице `employee_rates` для конкретного `user_id`.
   - Если персональная ставка не задана, применяется системный дефолт 30%.
3. **Атомарная транзакция привязки (`linkLeadToSeller`)**:
   - Проверяет отсутствие коллизий: телефон продавца не должен быть уже привязан к другому лиду.
   - Обновляет лид: `seller_phone`, `status = 'Подписан'`, `linked_at = now()`.
   - Закрепляет консультанта за продавцом в `sellers.manager_id`.
   - Добавляет запись в таблицу `connections`:
     - `seller_phone`, `seller_name`, `store`;
     - `manager_id` (консультант), `assigned_by` (инициатор);
     - `plan_id`, `plan_price`, `connection_fee_percent`, `connection_fee_amount` (`plan_price * percent / 100`);
     - `accrual_month` (`YYYY-MM`);
     - `client_status = 'новый'`, `status = 'подключен'`;
     - `maintenance_months_limit = 3`, `maintenance_months_accrued = 0`.

### 1.2. Модальное окно маппинга (`components/leads/LeadSellerMappingModal.tsx`)
- Эстетика Apple Island Glassmorphism (`backdrop-blur-2xl bg-white/90 dark:bg-zinc-900/90 rounded-3xl`).
- Поиск по имени, магазину или номеру телефона с подсветкой результатов.
- Список свободных продавцов с бейджами тарифов и датами создания.
- Интерактивная карточка предварительного расчета комиссии:
  - Отображение выбранного тарифа и стоимости в сомах;
  - Персональная процентная ставка консультанта;
  - Итоговый мгновенный бонус в сомах с выделением изумрудным цветом.
- Защита от дублирующих отправок и блокировка при отсутствии прав (роль `smm`).

### 1.3. Интеграция в модуль лидов (`app/leads/page.tsx`)
- Кнопка «Привязать продавца» в `EntityModal` (в секции быстрых действий `QuickActionBar`) вызывает `LeadSellerMappingModal`.
- При успешной привязке карточка обновляется, статус переводится в «Подписан», всплывает уведомление с суммой начисленного бонуса.

### 1.4. Модуль «Подключения» (`app/connections/actions.ts` и `app/connections/page.tsx`)
1. **Серверный слой (`app/connections/actions.ts`)**:
   - `getConnections`: Выборка с пагинацией, фильтрацией по расчетному месяцу (`accrualMonth`), статусу сопровождения (`clientStatus`) и поиску.
   - RBAC: администратор видит всех клиентов, консультант — только закрепленных за ним (`manager_id = current_user_id`), SMM получает статус отказа в доступе.
   - `getConnectionsStats`: Подсчет общего числа подключений, новых за текущий месяц, клиентов в сопровождении и суммарного объема бонусов к выплате.
   - `updateConnectionClientStatus`: Смена статуса сопровождения (`новый`, `подключен`, `сопровождение`, `готов`, `отменен`), разрешенная только администратору.
   - `getAccrualMonthsList`: Формирование списка периодов для селектора.
2. **Пользовательский интерфейс (`app/connections/page.tsx`)**:
   - Внедрение `AppLayout` с контекстом текущего пользователя.
   - Верхний информационный блок с селекторами расчетного месяца и статуса клиента.
   - 4 KPI-карточки Apple Island: «Всего подключений», «Новые за месяц», «В сопровождении», «Бонусы к начислению».
   - Универсальный реестр `DataJournal` с адаптивным переключением между табличным (ПК) и карточным (мобильный) режимами.
   - Модальное окно просмотра деталей и управления статусом жизненного цикла клиента.
   - Экран блокировки доступа для роли SMM с перенаправлением на `/leads`.
