# Спецификация UI/UX дизайна и интерфейсных компонентов SotkaCRM

Документ регламентирует требования к пользовательскому интерфейсу, дизайн-системе в стиле Apple Island (островной дизайн с матовыми поверхностями), адаптивным лейаутам и универсальному компоненту отображения данных для мобильных устройств и ПК.

---

## 1. Концепция дизайн-системы (Apple Island Style & Glassmorphism)

Интерфейс строится по модульной «островной» концепции: функциональные блоки не прилипают к краям экрана монолитом, а представляют собой парящие скруглённые панели с эффектом матового стекла (Frosted Glass / Glassmorphism).

* **Поверхности и матовость:**
* Фон подложки: глубокий нейтральный фон (`bg-zinc-100` в светлой теме, `bg-black` или `bg-zinc-950` в тёмной).
* Плавающие островки: полупрозрачные контейнеры с размытием заднего плана (`backdrop-blur-xl bg-white/75 border border-white/20 shadow-sm` для светлой темы; `backdrop-blur-xl bg-zinc-900/75 border border-zinc-800/40 shadow-2xl` для тёмной темы).


* **Скругления (Border Radius):**
* Основные рабочие островки и карточки: `rounded-2xl` (16px) или `rounded-3xl` (24px).
* Кнопки, бейджи и поля ввода: `rounded-xl` (12px) или `rounded-full`.


* **Иконографика (Строгий контурный стиль):**
* Использование исключительно линейных контурных иконок пакета **Lucide React** (`stroke-width="1.75"` или `2`).
* Полный запрет на эмодзи (никаких 📱, 💰, 👤 в интерфейсе). Все статусы, категории и кнопки снабжаются исключительно контурной векторной графикой.


* **Двойная цветовая палитра (Light / Dark Theme):**
* Переключение через CSS-переменные или Tailwind-класс `dark:`.
* Светлая тема: контрастный темный текст (`text-zinc-900`), мягкие серые границы (`border-zinc-200/60`), приглушенные акценты.
* Тёмная тема: нейтральный светлый текст (`text-zinc-100`), темные разделители (`border-zinc-800/60`), отсутствие чистого белого фона у панелей.

## 2. Глобальный адаптивный лейаут (Desktop vs Mobile)

Каркас приложения разделен на три слоя: фиксированный верхний островок, навигационный блок (боковой на ПК / нижний на смартфоне) и независимая скроллируемая рабочая область по центру.

```
       ДЕСКТОП (PC Mode)                                 МОБИЛЬНЫЙ (Mobile Mode)
+------------------------------------------+       +-----------------------------------+
|  [Матовый плавающий Top Header]          |       | [Плавающий Top Header: Название,  |
+------------------------------------------+       |  кнопка Лупы и Фильтра]           |
| Скрываемый  | Скроллируемая              |       +-----------------------------------+
| боковой     | центральная                |       |                                   |
| матовый     | рабочая область            |       | Скроллируемая лента               |
| сайдбар     | (динамическая замена       |       | контента (карточный вид)          |
| (Desktop)   | компонентов страниц)       |       |                                   |
|             |                            |       |               [ FAB: Круглая   ]  |
|             |                            |       |               [ кнопка «+»     ]  |
|             |                            |       +-----------------------------------+
|             |                            |       | [Матовый нижний плавающий бар]    |
+------------------------------------------+       +-----------------------------------+

```

### 2.1. Режим десктопа (Экран от 1024px)

* **Левая панель навигации (Sidebar Island):**
* Вертикальный матовый островок с отступом от левого края и отступом сверху/снизу (`top-4 left-4 bottom-4 w-64 fixed`).
* Функция скрытия/коллапса: сворачивается в узкую полосу (`w-18`) с отображением только линейных иконок по кнопке-триггеру, расширяя рабочую зону.
* Содержит: логотип SotkaCRM, список модулей (Лиды, Продавцы, Оплаты, Подключения, Выплаты, Справочники), профиль пользователя внизу.


* **Верхний плавающий островок (Top Header Island):**
* Фиксированная горизонтальная панель (`fixed top-4 right-4 z-30`). Автоматически адаптирует ширину с учетом состояния бокового меню (`left-72` при раскрытом меню, `left-24` при свернутом).
* Содержит: хлебные крошки/название текущего раздела, глобальную строку быстрого поиска, переключатель темы (Солнце/Луна), статус синхронизации API (для админа), мини-аватар профиля.


* **Центральная область:** Скроллится независимо (`overflow-y-auto pt-24 px-4 pb-6`). При переходе между страницами меняется исключительно этот контейнер, панели остаются зафиксированными без мерцания.

### 2.2. Мобильный режим (Экран до 1023px)

* **Верхний мобильный островок:**
* Зафиксирован сверху экрана с учетом системного отступа (`safe-area-inset-top`).
* Левая часть: заголовок текущего открытого модуля.
* Правая часть: две компактные контурные кнопки — **Лупа** (`Search`) и **Фильтр** (`SlidersHorizontal`).
* *Механика поиска:* При нажатии на лупу плавно выезжает/раскрывается матовая строка ввода с автофокусом и кнопкой сброса (`X`).


* **Нижний навигационный островок (Bottom Bar Island):**
* Матовая плавающая таблетка с отступом от нижнего края: `fixed bottom-4 left-4 right-4 h-16 rounded-2xl z-40 backdrop-blur-xl`.
* Равномерно распределенные 4-5 ключевых контурных иконок с подписями минимального размера (Лиды, Продавцы, Финансы, Профиль).


* **Плавающая кнопка добавления (FAB - Floating Action Button):**
* Круглая кнопка с иконкой линейного плюса (`Plus`, `stroke-width="2.5"`).
* Размер: `w-14 h-14` (56x56px), цвет акцентный (глубокий индиго / ультрамарин или контрастный графит с белым плюсом).
* Позиционирование: строго в правом нижнем углу экрана над нижним островком (`fixed bottom-24 right-5 z-50 shadow-lg active:scale-95 transition-transform`). Рассчитана на нажатие большим пальцем правой руки при управлении одной рукой.

## 3. Универсальный компонент отображения данных (`DataJournal`)

Для исключения дублирования верстки во всех разделах системы (Лиды, Продавцы, Платежи, Выплаты, Торговые точки) используется **единый универсальный полиморфный компонент `DataJournal**`.

Компонент поддерживает два режима отображения с сохранением пользовательских настроек в `localStorage` браузера:

1. **Табличный вид (`Table View`):** открывается **по умолчанию на ПК**.
2. **Карточный вид (`Card View`):** открывается **по умолчанию на смартфонах**.

### 3.1. Сравнительная матрица возможностей режимов

| Параметр | Табличный вид (Desktop Default) | Карточный вид (Mobile Default) |
| --- | --- | --- |
| **Отображение данных** | Многоколоночная компактная сетка | Лента плавающих матовых карточек |
| **Ширина столбцов** | Интерактивное изменение (drag-to-resize) | Адаптивная ширина карточки (100%) |
| **Порядок полей** | Drag-and-drop перетаскивание колонок | Фиксированная иерархия блоков внутри карточки |
| **Видимость полей** | Чекбоксы в меню «Колонки» | Чекбоксы в настройке «Поля карточки» |
| **Сортировка** | Клик по заголовку любого столбца (ASC/DESC) | Выпадающий список сортировки в фильтр-баре |
| **Фильтрация** | Быстрый inline-фильтр или общий фильтр | Выдвижное модальное окно (Bottom Sheet) |
| **Быстрые действия** | Контекстное меню строки / кнопки в столбце | Прямые кнопки на карточке (Звонок, WA, Статус) |

---

### 3.2. Требования к табличному режиму (Table View)

* **Sticky Header:** Шапка таблицы всегда зафиксирована сверху при вертикальном скролле списка.
* **Кастомизация колонок (Column Visibility & Ordering):**
* Выпадающее меню «Настройка таблицы»: список всех доступных полей с чекбоксами видимости.
* Возможность перетаскивания названий колонок влево/вправо для изменения их очередности.
* Запоминание ширины колонок: разделители заголовков можно перетягивать мышью для изменения ширины столбца.


* **In-cell бейджи:** Статусы и ответственные сотрудники отображаются в виде цветных контурных или пастельных пилюль (`Badge`).

---

### 3.3. Требования к карточному режиму (Card View)

* **Анатомия карточки:**
* Верхняя строка: Индикатор статуса (цветная плашка) слева, дата/время справа.
* Основной блок: Имя клиента / магазина крупным жирным шрифтом, контактные данные, комментарий.
* Нижняя строка (Action Bar):
* Кнопка прямого GSM-вызова (`href="tel:..."`).
* Кнопка диалога WhatsApp (`href="[https://wa.me/](https://wa.me/)..."`).
* Кнопка Instagram Direct.
* Компактный селектор смены статуса (dropdown прямо на карточке).




* **Скрытие полей:** Пользователь в настройках может отключить отображение второстепенных параметров (например, скрыть дату создания или ник Instagram, оставив только телефон и имя).

---

### 3.4. Фильтрация, сортировка и пагинация

* **Универсальный фильтр:**
* Позволяет добавить произвольное количество правил по формуле: `[Поле] [Условие: равно, содержит, больше, меньше] [Значение]`.
* Фильтрация по любому атрибуту сущности (дата, сумма, сотрудник, телефон, статус).


* **Настраиваемая пагинация (Server-side Pagination):**
* Блок управления пагинацией расположен внизу реестра: выбор лимита записей на страницу (10, 25, 50, 100) и кнопки перелистывания (`Предыдущая`, `1`, `2`, `...`, `Следующая`).
* Исключает передачу на клиент избыточных массивов данных, защищая память устройства от зависания.



---

### 3.5. Система цветовой индикации

В системе действует настраиваемая цветовая кодировка для быстрого визуального считывания:

* **Индикаторы статусов воронки лидов:**
* `Открыт` — неоновый синий / лазурный (`bg-blue-500/15 text-blue-600 dark:text-blue-400 border-blue-500/30`).
* `Обработан` — фиолетовый (`bg-purple-500/15 text-purple-600 dark:text-purple-400 border-purple-500/30`).
* `Назначен` — янтарный / оранжевый (`bg-amber-500/15 text-amber-600 dark:text-amber-400 border-amber-500/30`).
* `Подписан` — изумрудный / зеленый (`bg-emerald-500/15 text-emerald-600 dark:text-emerald-400 border-emerald-500/30`).
* `Отмена` — нейтральный серый или приглушенный коралловый (`bg-rose-500/15 text-rose-600 dark:text-rose-400 border-rose-500/30`).


* **Индикаторы сотрудников:**
* Каждому консультанту и SMM-специалисту назначается уникальный визуальный цветовой маркер или двухбуквенный круглый аватар с индивидуальным цветом обводки, чтобы в таблице и ленте мгновенно идентифицировать ответственного.

## 4. Профиль пользователя и персональная аналитика

Каждый авторизованный сотрудник имеет персональный раздел, доступный через клик по аватару/имени в нижнем баре или сайдбаре:

* **Карточка сотрудника (Личные данные):**
* ФИО, текущая системная роль (`admin`, `consultant`, `smm`), рабочий логин, телефон.
* Переключатель темы оформления (Светлая / Тёмная / Системная).
* Кнопка выхода из системы (`LogOut`).


* **Островок персональной статистики (KPI Dashboard):**
* Для **SMM**: счетчик созданных лидов за день, неделю, расчетный месяц; процент отмененных лидов.
* Для **Консультанта**:
* Количество лидов в активной обработке.
* Количество успешно закрытых сделок (лиды в статусе «Подписан»).
* Текущая сумма начисленной комиссии за первичное подключение клиентов за текущий месяц (сом).
* Сумма начислений за ежемесячное сопровождение (сом).


* Для **Администратора**: общие сводные показатели воронки, выручка платформы, статус последней синхронизации API.
